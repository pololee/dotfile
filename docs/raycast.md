# Raycast

Raycast is the launcher and window manager for this setup. Rectangle is no longer used.

Window-management shortcuts are configured in **Raycast Settings → Extensions → Window Management**. They are intentionally documented rather than copied from `~/.config/raycast`: the files currently stored there are authentication credentials, not portable preferences.

On a new Mac:

1. Install Raycast with the root `Brewfile`.
2. Sign in to sync Raycast settings, or configure the preferred Window Management shortcuts in the UI.
3. Do not commit Raycast access-token files or an unreviewed settings export.
