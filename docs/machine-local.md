# Machine-local config

The repo holds only what is true on **every** laptop. Everything tied to one
employer, host, or credential lives in untracked files in `$HOME`.

## The three escape hatches

| File | Loaded | Use it for |
| --- | --- | --- |
| `~/.zshrc.pre.local` | **before** `zsh/conf.d/[0-8]*.zsh` | Centrally-managed shellinit that the portable config is meant to override (e.g. a Chef-managed `~/.stripe/shellinit/zshrc` that sets a 2000-line history) |
| `~/.zshrc.local` | after `[0-8]*`, before `99-plugins-last.zsh` | Work aliases, internal env vars, functions that shell out to internal CLIs |
| `~/.gitconfig.local` | last `[include]` in `~/.gitconfig` | Commit identity, signing key, `hooksPath`, `maintenance.repo` paths, enterprise credential usernames |

`install.sh` seeds the two `.local` files from `templates/` if they don't exist,
and never overwrites them. `*.local` is in `.gitignore` as a second line of
defence.

Order is the reason `.pre.local` exists: shellinit has to run first so the
portable config can win, but plugins in `99-plugins-last.zsh` have to run after
everything, including `.local`.

## What got moved out of the tracked config

Extracted from the original `~/.zshrc` into `~/.zshrc.local`:

- `PAY_SSH_CONNECTOR_AUTO_PREFERS_PTY_CLI`
- `payserver` / `ps` aliases (hardcoded `~/stripe/pay-server`)
- `remote-devbox()` — wraps `pay remote list` / `pay remote ssh`
- sourcing `~/.zsh/herdr-remote.zsh` (devbox bootstrap, sshbastion cert checks,
  reconnect loop). The file itself stays at `~/.zsh/herdr-remote.zsh`; its
  counterpart lives in the internal `devbox` repo.

Extracted from the original `~/.gitconfig` into `~/.gitconfig.local`:

- `user.email`, `user.signingkey`
- `core.hooksPath = /etc/stripe/git_hooks`
- `maintenance.repo` × 3
- `merge "stripe-noop"` driver
- `credential "https://github.com".username`
- `protocol.ext.allow` / `protocol.version`

Note that `~/.config/herdr/config.toml` **is** tracked — herdr is a public tool
(homebrew/core, <https://herdr.dev>) and that file is pure key/UI preference.
Only the Stripe-specific *wrapper* is local.

## Deliberately not in the repo

| Path | Why |
| --- | --- |
| `~/.config/direnv/direnv.toml` | Header says "centrally-managed by Salt. DO NOT EDIT"; the whitelist is all `~/stripe/*` paths |
| `~/.config/tmuxinator/*.yml` | `pay-server.yml` / `sjs-oss.yml` are work project layouts |
| `~/.config/{pay-server,gocode,zoolander,mint,stripe}` | Work tooling state |
| `~/.config/island`, `~/.config/iterm2` | Host-local sockets and an iTerm2 bridge script for one machine |
| `~/.config/raycast` | `extensions/` are installed bundles (including internal ones) and `config.json` is 18 bytes of machine state — nothing meaningfully versionable. Raycast's own Cloud Sync is the right tool |
| `~/.claude/settings.json`, `~/.codex/config.toml` | **Both apps rewrite these files during a session** — Claude Code re-adds deleted keys and alphabetizes, Codex bumps a timestamp. A symlink here means fighting the app on every run. Use each vendor's own sync mechanism |
| `~/.fzf_init.zsh` | 22 KB generated by fzf. `conf.d/40-fzf.zsh` runs `fzf --zsh` instead, so it tracks the installed version |
| `~/.config/nvim/lua/plugins/example.lua` | LazyVim's stock `if true then return {} end` sample — dead weight |
